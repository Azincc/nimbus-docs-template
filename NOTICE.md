# Nimbus template provenance

This project includes the visible static Cloudflare starter generated by
`@cloudflare/create-nimbus-docs@0.7.2` with `--deploy cloudflare --content empty`.
The generated template is pinned to `templates-v0.7.2` and uses
`@cloudflare/nimbus-docs@0.13.0` and Astro `7.0.9`. Wrangler is pinned to
`4.127.0`, with the compatibility date required by `cloudflare/templates`.

Upstream: <https://github.com/cloudflare/nimbus>

The example site's logo is the unmodified official Nimbus asset from
<https://nimbus-docs.com/logo.svg>. It identifies the upstream Nimbus project,
not an original brand owned by this template. The submission icon embeds the
same asset with transparent padding and uniform scaling for a 16:9 canvas.

Nimbus is distributed under the MIT license. Its layouts, components, styles,
and static routes are preserved here with adaptations for source synchronization,
the document homepage, branding, and build provenance. `nimbus.json` retains the
upstream scaffold metadata. Exact dependency resolutions are recorded in the
npm and pnpm lockfiles (the official collection keeps its pnpm lockfile at the repository root).

The template also adapts ordinary Markdown serialization to Nimbus 0.13's
MDX-based authored-link scanner, keeps Sätteri's native package external during
Astro prerendering, and builds Pagefind through its Node API for consistent
Windows and Linux command execution. These adaptations do not modify packages
in `node_modules`.
